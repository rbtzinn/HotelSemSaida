# Hotel Sem Saída — instruções para o Codex

A fonte única de verdade do projeto é o **`CLAUDE.md`**, na raiz. Leia-o inteiro antes de qualquer tarefa e siga tudo o que está lá (regras de design, estrutura, estilo de código, testes, LF, validação headless, perguntar ao Roberto antes de decisões de design).

Ao terminar uma etapa, atualize o `CLAUDE.md` (não este arquivo), para que o Claude Code e o Codex trabalhem com a mesma informação.

Os agentes em `.codex/agents/` seguem as mesmas regras; em conflito, vale o `CLAUDE.md`.
